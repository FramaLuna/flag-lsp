# Flag for VS Code

Syntax highlighting for [Flag](https://github.com/FramaLuna/flag-lang), errors as you type, hover and go to definition.

## Requirements

`flagc`, see the [Installation](https://github.com/FramaLuna/flag-lang#installation) of Flag.


## Settings

- `flag.memory`: also show the warnings of the memory checker, `flagc -memory`. It's off because it makes every check slower
- `flag.exclude`: folders or files, relative to the workspace folder, that flagls leaves out
- `flag.server`: the flagls to run instead of the one that comes with the extension.
