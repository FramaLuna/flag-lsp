# Changelog

## 0.2.0

For Flag 0.1.0 or later.

- The extension comes with flagls for Linux x86_64, macOS arm64 and Windows x86_64, and `flag.server` runs another one
- flagls works on Windows
- `flag.memory` shows the warnings of the memory checker, `flagc -memory`, off by default
- When VS Code doesn't find `flagc`, a message says how to install it instead of an error on every file, and `Don't show again` hides it

## 0.1.0

The first release of flag-lsp, for Flag 0.1.0.

- `flagls` for Linux x86_64 and macOS arm64: errors as you type, hover and go to definition
- The VS Code extension, `flag-0.1.0.vsix`: syntax highlighting, and flagls for everything else
